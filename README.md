# 📊 Data & Finance Projects

Добро пожаловать в мой репозиторий с проектами на стыке аналитики данных и финансов.

Основной фокус — использование данных для принятия **финансово обоснованных решений**: от оценки стоимости активов до оптимизации бизнес-показателей.

## 🚀 Проекты

### 1. 💰 Финансовая модель инвестиционного проекта (FMCG)

- **Описание:**  
  Построение финансовой модели для оценки инвестиционной привлекательности нового продукта FMCG компании.

- **Что сделано:**
  - Построен прогноз выручки и затрат на основе драйверов роста
  - Реализована логика формирования P&L и Cash Flow на горизонте 3 лет
  - Рассчитаны FCFF / FCFE
  - Проведена оценка стоимости проекта методом DCF
  - Рассчитаны Enterprise Value и Equity Value
  - Определён срок окупаемости проекта

- **Результат:**  
  Получена комплексная оценка инвестиционной привлекательности проекта и сформирована база для принятия стратегического решения о запуске продукта.

- **Excel-таблица**  
  https://github.com/TricksSeeker/Portfolio/blob/main/FMCG_financial_model.xlsx

### 2. 🏙️ Анализ рынка недвижимости (Яндекс.Недвижимость)

- **Описание:**  
  Анализ рынка жилой недвижимости Санкт-Петербурга с целью определения факторов, влияющих на стоимость объектов.

- **Данные:**  
  Исторические данные объявлений (цены, характеристики квартир, география, инфраструктура).

- **Что сделано:**
  - Проведена очистка и предобработка данных (работа с пропусками и аномалиями) :contentReference[oaicite:0]{index=0}
  - Выявлены ключевые факторы, влияющие на цену (площадь, удалённость от центра, характеристики объекта)
  - Проведён EDA и визуализация распределений
  - Построена регрессионная модель оценки стоимости недвижимости

- **Финансовый смысл:**  
  Модель позволяет:
  - оценивать справедливую стоимость объектов
  - выявлять недооценённые/переоценённые активы
  - использовать результаты для инвестиционных решений на рынке недвижимости

### 3. 📱 Анализ поведения пользователей и влияние на выручку

- **Описание:**  
  Анализ пользовательского поведения в мобильном приложении продуктового стартапа с целью оптимизации конверсии и бизнес-метрик.

- **Данные:**  
  Лог-файлы пользовательских действий (~240k событий, ~7.5k пользователей) :contentReference[oaicite:1]{index=1}

- **Что сделано:**
  - Построена воронка продаж и рассчитаны конверсии на каждом этапе
  - Выявлены ключевые точки потерь пользователей
  - Проведён A/A/B тест и проверка статистической значимости изменений
  - Оценено влияние продуктовых изменений на поведение пользователей

- **Финансовый смысл:**  
  Результаты анализа позволяют:
  - увеличить конверсию → рост выручки
  - снизить потери пользователей на ключевых этапах
  - принимать продуктовые решения на основе экономического эффекта

- **Код:**  
  https://github.com/TricksSeeker/Portfolio/blob/main/modile_application_analysis.ipynb

### 4. 📊 Когортный анализ NPS (МТС)

- **Описание:**  
  Анализ удовлетворённости пользователей (NPS) по когортам: продукт, регион, жизненный цикл клиента.

- **Что сделано:**
  - Сегментация пользователей по ключевым бизнес-факторам
  - Выявление проблемных зон (низкий NPS)
  - Сравнительный анализ когорт
  - Визуализация результатов

- **Финансовый смысл:**  
  - NPS напрямую связан с удержанием клиентов (retention)
  - Улучшение клиентского опыта → рост LTV
  - Выявление слабых продуктов → оптимизация аллокации ресурсов

- **Код:**  
  https://github.com/TricksSeeker/Portfolio/blob/main/EDA_NPS.ipynb

## 🧠 Ключевая идея

Я рассматриваю аналитику как инструмент для ответа на главный вопрос бизнеса:  
**создаёт ли это ценность и имеет ли это финансовый смысл.**

Любое решение — продукт, стратегия или инвестиция — в конечном итоге сводится к цифрам.
